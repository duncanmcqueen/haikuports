Additional packages for HaikuPorts

A personal repository for Haiku R1/beta6 x86_64. Keep the official Haiku and HaikuPorts repositories enabled.

Some packages may have been created with AI assistance. Human review and validation occur, but defects remain possible. Everything is provided AS-IS, without warranties. This repository is not endorsed by Haiku or HaikuPorts.

Configure Haiku

pkgman add-repo https://duncanmcqueen.github.io/haikuports/r1beta6/x86_64
pkgman install nodejs22 npm

Node 22.23.3 currently loads ICU 77; this repository supplies that runtime automatically. SoftwareUpdater uses the saved repository registration for future updates.

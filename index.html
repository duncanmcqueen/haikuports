Install

Open Terminal on Haiku R1/beta6 x86_64 and run these commands.

1. Add the repository

pkgman add-repo https://duncanmcqueen.github.io/haikuports/r1beta6/x86_64
pkgman refresh DuncanHaikuPackages

2. Install Node.js

pkgman install nodejs22 npm
node --version
node -p 'process.versions.icu'

Node 22.23.3 loads ICU 77, so this repository supplies icu77 and pkgman installs it automatically. If Node.js 20 is installed, Node 22 conflicts with it; inspect the solver proposal before accepting.

3. Install the pi coding agent and its Haiku skills

pkgman install pi haiku_agent_library
pi install /boot/system/data/haiku-agent-library
pi

pi is a separate project. Once Node.js 22 is installed, pi can be installed like normal, the same way as on any other system — see the pi website at pi.dev and its documentation at pi.dev/docs/latest for the install and setup instructions. This repository only adds a ready-built Haiku package for convenience. If the pi command is not found, reboot Haiku: new system packages become available on the next boot. Then configure pi with a model and API key as the pi documentation describes.

What is haiku_agent_library?

It is a package of Agent Skills for AI coding assistants (pi, Maki, and anything that reads AGENTS.md and Agent Skills) that work on Haiku OS code. It installs under /boot/system/data/haiku-agent-library and contains:

  • haiku-api skill — a native Haiku C++ API model plus the Haiku Book sources (.dox) for BApplication, BWindow, BMessage, layouts, the Storage Kit, networking, and more, with an index to search.
  • haikuports-recipe skill — how to write, build, patch, and submit a HaikuPorts recipe, with a variable reference and a starter template.
  • AGENTS.md rules — always-on reminders that Haiku is not Linux: package-managed read-only /boot/system, libnetwork/libbsd, and how to look up API documentation.

Register it with pi using pi install /boot/system/data/haiku-agent-library, then check it inside pi with /skill:haiku-api.

Updates

pkgman add-repo saves the repository across restarts, and SoftwareUpdater uses it for future updates. Update from Terminal any time: 

pkgman refresh DuncanHaikuPackages
pkgman update

You can also add it in Deskbar → Preferences → Repositories with the + button. Keep Haiku, HaikuPorts, and DuncanHaikuPackages enabled. To stop using it: pkgman drop-repo DuncanHaikuPackages.
